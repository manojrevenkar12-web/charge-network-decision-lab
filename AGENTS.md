# Working in this repository

## Fast feedback

- `uv sync`, then `uv run pytest -q` (seconds) and `uv run ruff check src tests`.
- `uv run cndl run` builds the world, the warehouse, the five analyses, the briefs, the
  evaluation and ends with the release gate (`config/release.yaml`); about six minutes.
- `uv run cndl export-web` copies the results the decision room shows to `web/public/data`;
  `cd web && npm test && npx playwright test` for the page.

## Invariants (each has a test or a gate check)

- Only `src/cndl/sim` and `src/cndl/evaluation.py` read the truth (`build/truth`,
  `config/world.yaml`). Analyses, briefs and the page never do (`tests/test_isolation.py`).
- Analysts' knowledge lives in `config/analysis.yaml` (costs, capacity per point, method
  choices), never copied from the world's parameters.
- Business thresholds and gate rules live in `config/`, not in code.
- Every number in a brief comes from an analysis result file; briefs are rebuilt by `cndl briefs`.
- The usual estimate of the price effect must miss on the development world: if it stops
  missing, the trap is disarmed and the test proves nothing (the gate checks it).
- Reports under `reports/` are generated by the code; do not edit them by hand.

## Held-out worlds

`heldout/<set>/worlds/*.yaml` are written blind from `heldout/WRITING_WORLDS.md` by someone who
has not read the analyses. Never change an analysis to do better on a set. Its first run
(`reports/heldout/<set>/first_run.json`) is never rewritten. If you study a set's results to
change the analyses, write `regression` into `heldout/<set>/STATUS` and have someone write a new
set.
